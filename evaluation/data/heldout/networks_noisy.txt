Okay so um today uh we are going to talk about how data actually gets across the internet. So the internet uses a layered model, right, a layered model, and each layer has its own protocols. The transport layer is responsible for delivering data between applications on two hosts. The most common transport protocol is TCP, which stands for transmission control protocol, TCP gives reliable delivery. Um TCP gives reliable delivery by using sequence numbers and acknowledgments. When the sender transmits a segment it starts a timer, and if no acknowledgment arrives before the timer expires the sender retransmits the segment. Before any data flows TCP sets up a connection using a three way handshake, a three way handshake. The three way handshake uses SYN and ACK packets. Now congestion, you know, congestion is what happens when too many senders push too much data into the network and the routers drop packets. TCP controls congestion with a congestion window which limits how much unacknowledged data the sender may have in flight. In the slow start phase the congestion window doubles every round trip time. When a packet is lost TCP assumes the network is congested and it cuts the congestion window in half. This is called congestion control, congestion control keeps the network from collapsing. Um so remember that flow control is different, flow control protects the receiver and congestion control protects the network. Finally the domain name system, DNS. Uh a DNS resolver asks a chain of name servers, the root server first, then the top level domain server, and finally the authoritative server.
